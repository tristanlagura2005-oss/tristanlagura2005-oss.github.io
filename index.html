Case study 01

Large-Scale Shopify Catalog Management

Supported the rebuilding and reorganization of a Shopify product catalog by collecting, cleaning, structuring, and reviewing approximately 37,000 products.

ResultApproximately 37,000 products collected, edited, prepared, and imported over approximately two months.

Overview

Managed high-volume product information for a Shopify catalog and supported store-content reorganization.

Challenge

Large amounts of product data needed consistent titles, descriptions, images, specifications, variants, inventory fields, and Shopify-compatible formatting.

Responsibilities

  • Collect product information
  • Clean titles and descriptions
  • Organize images and dimensions
  • Prepare variants and inventory data
  • Organize vendors, tags, collections, and product types where applicable

Process

  1. Collect and review source information
  2. Clean and normalize product content
  3. Map fields into Shopify-compatible CSV structure
  4. Prepare and review imports
  5. Check consistency after import

Tools

Shopify, Microsoft Excel, Google Sheets, CSV, and Python.

Scope note

This case study reflects catalog and store-content support. It does not claim sole responsibility for designing or programming the entire Shopify website.

Case study 02

Python Product Collection & Data Automation

Created a Python scraper that collected product information from multiple websites, processed web content, and organized the results for spreadsheet review and Shopify imports.

ResultA repeatable collection workflow that reduced repetitive manual gathering while keeping human review before import.

Overview

Built a structured product-collection workflow using Python and common data libraries.

Challenge

Manually collecting and reformatting product details across multiple websites was repetitive and difficult to keep consistent.

Responsibilities

  • Request and parse web pages
  • Extract product details
  • Normalize and structure results
  • Prepare spreadsheet and CSV output
  • Configure relevant inventory fields
  • Review and validate data before import

Process

  1. Collect source pages
  2. Parse useful content
  3. Clean and structure fields
  4. Export to tabular data
  5. Review exceptions and validate output

Tools

Python, Requests, BeautifulSoup, Pandas, pathlib, urllib, CSV, and Excel.

Measurement note

The workflow reduced repetitive manual collection, but no exact time-saved figure is claimed because it was not formally measured.
